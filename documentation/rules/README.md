# Rules for writers and reviewers

Load all of these before writing or reviewing:
1. `voice.md` — language, teaching, zero repetition, callouts, code, images.
2. `templates.md` — page templates per genre and the reference description file format.
3. `owners.md` — notion → owner page registry (zero repetition).
4. `terms.md` — controlled terms, source of the glossary.

Facts come from the code of the repository (`core/`, `base/`, `backend/`, `tool/`; demos = idiomatic usage, tests = exact behavior), never from the old docs (`documentation/legacy/`), which are raw material only and contain errors.
