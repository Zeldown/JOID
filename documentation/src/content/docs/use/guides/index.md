A guide reaches one result, step by step, with a check after each step and a list of causes when the result does not show.
Each guide links to the Learn pages that explain the notions it uses.

| Guide | You get |
|---|---|
| [Make a modal popup](/use/guides/make-a-modal-popup/) | A confirmation popup that dims and blocks the screen under it. |
| [Show a video](/use/guides/show-a-video/) | A looping video with its sound, a progress bar and a play and pause button. |
| [Build a settings screen](/use/guides/build-a-settings-screen/) | Controls bound to a store that JOID keeps on disk. |
| [Replace a font](/use/guides/replace-a-font/) | One font family and its text styles, in every UI and in the tooltips. |
| [Write a node effect](/use/guides/write-a-node-effect/) | An effect of your own that any node can take. |
| [Build a UI kit](/use/guides/build-a-ui-kit/) | Skins for the controls, gathered in kits that switch at run time. |
| [Copy a mockup](/use/guides/copy-a-mockup/) | A screen rebuilt pixel for pixel from a mockup, checked by overlay. |
| [Ship your application](/use/guides/ship-your-application/) | A package on the prod jar, with your fonts and a data folder of the user. |
