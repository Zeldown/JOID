Learn: [Compare with a reference](/use/learn/running/testing/#compare-with-a-reference).

## of(int,int)

Returns a difference of that many pixels with that largest channel difference.

## getPixels()

Returns the number of pixels whose largest channel difference is above the tolerance; every pixel when the sizes differ.

## getMaximum()

Returns the largest channel difference found, from `0` to `255`.
