## COMPATIBILITY

A context that keeps the fixed pipeline: the state guard also turns off fog, lighting, alpha test and color material for JOID.

## CORE

A core profile, without the fixed pipeline.

## CORE_FORWARD_COMPATIBLE

A forward-compatible core profile, the only kind of core context on macOS.
