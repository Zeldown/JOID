---
summary: The event of `onHoverStart`, `onHover` and `onHoverEnd`, with the position of the pointer.
---

[[Node#onHoverStart]] fires on the frame where the node becomes hovered, [[Node#onHover]] on every frame while it is hovered, and [[Node#onHoverEnd]] on the frame where it stops being hovered.

Learn: [Hover and tooltips](/use/learn/interactivity/hover-and-tooltips/#react-when-the-pointer-enters-and-leaves).

## create(N,double,double)

Creates the event for a node and the position of the pointer.

## getMouseX()

Returns the horizontal position of the pointer, in design pixels of the UI.

## getMouseY()

Returns the vertical position of the pointer, in design pixels of the UI.
