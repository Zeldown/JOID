summary: A state that a host may leave set before a frame of JOID, which [[StateGuardContractSuite]] sets to check that JOID draws the same anyway.
---

Learn: [The suites](/build/testing-a-backend/#the-suites).

## BLEND

A blending of the host.

## SCISSOR

A scissor test left on.

## LOGIC_OP

A logic operation left on.

## FRONT_FACE

The front face reversed.

## ALPHA_TEST

An alpha test left on, on a compatibility context.

## PIXEL_STORE

Pixel storage parameters for uploads and reads.

## FRAMEBUFFER

A read framebuffer bound.

## PIXEL_BUFFER

A pixel buffer bound for uploads.

## POLYGON_MODE

Polygons drawn as lines.

## STENCIL_MASK

A stencil write mask.

## VERTEX_ARRAY

A vertex array of the host bound.

## CLIENT_ARRAYS

Client vertex arrays, on a compatibility context.

## COLOR_MATERIAL

Color material left on, on a compatibility context.

## DEPTH_FUNCTION

A depth function of the host.

## SAMPLER_OBJECTS

Sampler objects bound on the texture units.

## TEXTURE_PARAMETERS

Parameters changed on a texture of the host.

## EVERYTHING

Every other trap at once.
