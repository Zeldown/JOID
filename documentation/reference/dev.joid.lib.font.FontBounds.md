---
summary: The width and the height of a drawn or measured text, in design pixels.
---

Learn: [Text](/use/learn/describing-the-ui/text/).

## empty()

Returns bounds of zero width and zero height, the result of drawing an empty text.

## of(double,double)

Creates bounds of `width` × `height`.

## getWidth()

Returns the width, in design pixels.

## getHeight()

Returns the height, in design pixels.
