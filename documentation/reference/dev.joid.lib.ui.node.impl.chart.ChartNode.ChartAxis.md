---
summary: The base of the X and Y axes of a chart, created by `ChartAxis.x(...)` and `ChartAxis.y(...)`, with the name of the axis.
---
Learn: [Charts](/use/learn/going-further/charts/).

## x(String,String[])

Creates an X axis with this name and these labels, in order.

## y(String)

Creates a Y axis with this name.

## ChartAxis(String)

Called by a subclass with the name of the axis.

## getName()

The name of the axis.
