---
summary: Which steps of the pop transition a popup plays.
---
A transition set with [[UI#transition]] replaces the one these values give.

Learn: [Transitions](/use/learn/style-and-motion/transitions/#choose-what-a-popup-plays).

## NONE

The popup opens and closes at once.

## IN

The popup grows in when it opens and closes at once.

## OUT

The popup opens at once and shrinks out when it closes.

## IN_OUT

The popup grows in when it opens and shrinks out when it closes.

## isIn()

If `true`, the popup plays a transition when it opens.

## isOut()

If `true`, the popup plays a transition when it closes.

## isActive()

If `true`, the popup plays a transition on opening, on closing or both.
