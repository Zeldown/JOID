---
summary: The base class of the events about a UI, such as its input or its closing.
---

Learn: [Events](/use/learn/interactivity/events/#know-the-three-kinds-of-events).

## UIEvent(U)

Creates an event about a UI, from the constructor of a subclass.

## getUi()

Returns the UI that the event concerns, typed as the UI that the listener was added on.
