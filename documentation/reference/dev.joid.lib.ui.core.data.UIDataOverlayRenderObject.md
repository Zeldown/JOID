---
summary: The drawing options of an overlay for a running UI.
---
[[UIDataOverlayObject#render]] returns it.

Learn: [Overlays and popups](/use/learn/describing-the-ui/overlays-and-popups/).

## create()

Creates the options with the default values of [[UIDataOverlayRender]].

## always

If `true`, the overlay is drawn even when the UI bridge hides the overlays.

## aboveScreens

If `true`, the overlay is drawn above the screens.

## toString()

Returns the class and the value of every option, for logs.
