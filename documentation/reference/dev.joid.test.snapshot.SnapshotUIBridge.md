---
summary: The UI bridge of the snapshot runner: a window UI bridge with a `#323232` window background and an interface scale that the scenarios set.
---

Learn: [Testing your UIs](/use/learn/running/testing/).

## create()

Creates the bridge.

## getInterfaceScale(UI)

Returns the interface scale set by the `scale` command, `1D` by default.

## interfaceScale

Sets the interface scale of every UI of the bridge and returns the bridge.
