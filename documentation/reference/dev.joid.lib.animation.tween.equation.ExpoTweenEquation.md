---
summary: Easing curves along an exponential.
---

Each constant is also in [[TweenEquations]], as `EXPO_IN`, `EXPO_OUT` and `EXPO_IN_OUT`.

Learn: [Animation](/use/learn/style-and-motion/animation/).

## ExpoTweenEquation()

Creates a curve of this family, for a subclass.

## IN

Starts slowly, along an exponential.

## OUT

Ends slowly, along an exponential.

## IN_OUT

Starts and ends slowly, along an exponential.
