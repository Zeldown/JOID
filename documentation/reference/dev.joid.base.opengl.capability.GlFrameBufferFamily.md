summary: The family of framebuffer functions that an OpenGL context offers.

Learn: [Capabilities and paths](/build/base-modules/opengl/#capabilities-and-paths).

## CORE

The core functions of OpenGL 3.0 or `GL_ARB_framebuffer_object`.

## EXT

The functions of `GL_EXT_framebuffer_object`.

## UNSUPPORTED

No framebuffer object: JOID cannot draw on the context.
