---
summary: The overlay options of `@UIDataOverlay` for a running UI.
---
[[UI#getOverlay]] returns it; `active()` and `active(boolean)` read and change whether the UI is an overlay.

Learn: [Overlays and popups](/use/learn/describing-the-ui/overlays-and-popups/).

## create()

Creates the options of a UI that is not an overlay.

## active

If `true`, the UI is an overlay.

## render()

The drawing options of the overlay.

## interaction()

The input options of the overlay.

## toString()

Returns the class and the value of every option, for logs.
