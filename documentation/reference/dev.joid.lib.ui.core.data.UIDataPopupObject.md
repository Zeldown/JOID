---
summary: The popup options of @UIDataPopup for a running UI.
---
[[UI#getPopup]] returns it.
A change of the transition applies from the next frame, unless [[UI#transition]] has set a transition of its own.

Learn: [Overlays and popups](/use/learn/describing-the-ui/overlays-and-popups/).

## create()

Creates the options of a UI that is not a popup.

## isActive()

If `true`, the UI is a popup.

## setActive(boolean)

Makes the UI a popup or not.

## getTransition()

Which steps of the pop transition the popup plays.

## setTransition(PopupTransition)

Changes which steps of the pop transition the popup plays.
