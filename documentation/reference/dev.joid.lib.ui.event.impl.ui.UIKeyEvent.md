## create(U,Key,Key)

Creates the event for a UI, the place of the key and the key that the layout names.

## getKey()

Returns the key that the layout of the user names; use it for a shortcut.

## getPhysicalKey()

Returns the place of the key on a US QWERTY keyboard, whatever the layout; use it for a movement.
