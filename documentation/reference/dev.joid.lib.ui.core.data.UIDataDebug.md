---
summary: Annotation that turns off, for one UI, the profiler and the hot reload of dev mode.
---
Outside dev mode it changes nothing.

Learn: [UIs](/use/learn/describing-the-ui/uis/#configure-a-ui), [Dev tools](/use/get-started/dev-tools/).

## profiler()

If `true`, dev mode prints the time the UI takes to load and warns when a frame of the UI takes more than 16.66 ms to draw.

## hotreload()

If `true`, dev mode reloads the UI when its classes change.
