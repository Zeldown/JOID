---
summary: The two values that a toggle stands for, one while it is on and one while it is off.
---

[[BaseToggleNode#state]] creates one.

Learn: [Controls](/use/learn/interactivity/controls/#choose-between-two-values).

## of(T,B)

Creates the pair from the value while on and the value while off.

## getToggle()

Returns the value while the toggle is on.

## getBack()

Returns the value while the toggle is off.
