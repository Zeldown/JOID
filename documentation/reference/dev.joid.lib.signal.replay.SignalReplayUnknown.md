summary: Value that the replay cannot compute, such as a local variable whose value it does not know.
---

Learn: [How signals work](/use/in-depth/how-signals-work/).

## of(String)

Returns an unknown value described by `description` in the warnings.

## of(String,Object)

Returns an unknown value described by `description`, identified by `key`.

## getKey()

Returns the key of the value, or `null`.

## getDescription()

Returns how the warnings name the value.
