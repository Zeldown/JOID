## of(int[],long)

Creates a frame of `pixels`, `0xAARRGGBB` values of the whole animation size, shown for `duration` milliseconds.

## getPixels()

Returns the pixels of the frame.

## getDuration()

Returns how long the frame shows, in milliseconds.
