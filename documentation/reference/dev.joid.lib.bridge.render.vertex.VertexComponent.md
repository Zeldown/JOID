---
summary: The numeric type of the components of a vertex attribute.
---

[[VertexAttribute]] gives each attribute one of these types; a backend maps it to the vertex format of its API.

Learn: [Vertices](/build/pipeline/#vertices).

## getSize()

Returns the size of one component, in bytes.

## FLOAT

A 32-bit float.

## UNSIGNED_BYTE

An unsigned 8-bit integer.

## BYTE

A signed 8-bit integer.
