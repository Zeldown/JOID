---
summary: A point or a normal of an `ObjModel`, in model units.
---

Learn: [3D models](/use/learn/going-further/3d-models/).

## of(float,float)

Creates the point `x`, `y`, with `z` at `0F`.

## of(float,float,float)

Creates the point `x`, `y`, `z`.

## getX()

Returns the X coordinate.

## getY()

Returns the Y coordinate, up.

## getZ()

Returns the Z coordinate.
