---
summary: The kinds of OpenGL state that the journal records, in the order in which it restores them.
---

Learn: [The state journal](/build/embedding-in-a-host/#the-state-journal).

## READ_BUFFER

The read buffer of a framebuffer.

## FRAMEBUFFER

The framebuffer bound to the draw or the read target.

## RENDERBUFFER

The bound renderbuffer.

## PROGRAM

The current program.

## VERTEX_ATTRIBUTE

The pointer and the enabled flag of a vertex attribute.

## VERTEX_ARRAY

The bound vertex array.

## BUFFER

The buffer bound to a target.

## TEXTURE_PARAMETER

A parameter of a texture.

## TEXTURE

The texture bound to a unit.

## SAMPLER

The sampler bound to a unit.

## CURRENT_VERTEX_ATTRIBUTE

The current value of a vertex attribute.

## CAPABILITY

A capability switched with `glEnable`.

## BLEND_EQUATION

The blend equations.

## BLEND_FUNCTION

The blend factors.

## COLOR_MASK

The color write mask.

## CLEAR_COLOR

The clear color.

## CLEAR_DEPTH

The clear depth.

## CLEAR_STENCIL

The clear stencil value.

## DEPTH_MASK

The depth write mask.

## DEPTH_FUNCTION

The depth function.

## STENCIL_MASK

The stencil write masks.

## STENCIL_FUNCTION

The stencil functions.

## STENCIL_OPERATION

The stencil operations.

## VIEWPORT

The viewport.

## LINE_WIDTH

The line width.

## POLYGON_MODE

The polygon mode.

## FRONT_FACE

The winding of front faces.

## CULL_FACE

The culled face.

## PIXEL_STORE

A pixel storage parameter.

## ACTIVE_TEXTURE

The active texture unit, restored last.
