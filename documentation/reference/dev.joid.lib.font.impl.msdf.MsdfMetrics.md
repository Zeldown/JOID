Learn: [MSDF text](/use/in-depth/msdf-text/).

## of(float,float,float,float,float)

Creates the metrics from the line height, the ascender, the descender, the underline position and the underline thickness, each on 1 of the em.

## getLineHeight()

Returns the height of one line.

## getAscender()

Returns the height above the baseline.

## getDescender()

Returns the depth under the baseline, negative below it.

## getUnderlineY()

Returns the position of an underline relative to the baseline, negative below it.

## getUnderlineThickness()

Returns the thickness of an underline.
