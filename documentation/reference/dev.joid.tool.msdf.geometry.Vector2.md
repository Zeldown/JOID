Learn: [MSDF text](/use/in-depth/msdf-text/).

## of(double,double)

Returns the vector of those coordinates.

## add(Vector2)

Returns the sum of both vectors.

## subtract(Vector2)

Returns the difference of both vectors.

## scale(double)

Returns the vector multiplied by the factor.

## normalize()

Returns the vector of length 1 in the same direction.

## dot(Vector2)

Returns the dot product.

## cross(Vector2)

Returns the cross product, the signed area of both vectors.

## length()

Returns the length.

## getX()

Returns the abscissa.

## getY()

Returns the ordinate.
