---
summary: Immutable point of two or three `double` coordinates, compared by value.
---

Two points with the same coordinates are equal.

Learn: [Drawing shapes and text](/use/learn/going-further/drawing/).

## of(double,double)

Returns the point (`x`, `y`), with `z` at `0D`.

## of(double,double,double)

Returns the point (`x`, `y`, `z`).

## getX()

Returns the horizontal coordinate.

## getY()

Returns the vertical coordinate.

## getZ()

Returns the depth coordinate, `0D` for a point of the plane.
