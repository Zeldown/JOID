summary: An image of the host described for JOID: its image and view handles, its size and its number of levels.
---

Learn: [Show a texture of your application](/use/learn/describing-the-ui/media/#show-a-texture-of-your-application).

## of(long,long,int,int,int)

Describes the image of those handles, of that size in pixels and with that number of mipmap levels.

## getImage()

Returns the image handle.

## getView()

Returns the image view handle.

## getWidth()

Returns the width of the image, in pixels.

## getHeight()

Returns the height of the image, in pixels.

## getLevels()

Returns the number of mipmap levels, `1` without mipmaps.
