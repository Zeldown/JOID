---
summary: Function that gives the single line of a text tooltip.
---
Give it to [[Node#hover]]; the line is drawn by [[UI#drawHover]].

Learn: [Hover and tooltips](/use/learn/interactivity/hover-and-tooltips/#show-a-tooltip).

## get()

Returns the line to show, computed on every frame while the node is hovered; `null` shows no tooltip.
