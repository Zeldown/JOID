---
summary: The event of an `onX` listener of a node, which fires once a value changed.
---

It fires after each real change of the value, whatever asked for it: a gesture, a setter, a bound signal or a call such as `change(...)`.

Learn: [Controls](/use/learn/interactivity/controls/#react-to-a-change).

## create(N,V,V)

Creates the event for a node, the previous value and the new one.
