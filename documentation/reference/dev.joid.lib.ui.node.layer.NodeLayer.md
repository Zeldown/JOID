---
summary: Function that draws over a node, after its children, in the coordinates of the node.
---
Add one with [[Node#layer(NodeLayer)]].
It runs on the render thread at every frame where the node is drawn.

Learn: [Drawing](/use/learn/going-further/drawing/#choose-where-to-draw).

## draw(Node,double,double)

Draws over the node: `(0, 0)` is its top-left corner, and the mouse position is given in the same coordinates.
