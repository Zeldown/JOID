Tous les changements notables de JOID, groupés par version.

- [**6.0.0**](6.0.0.md) — 2026-04-18 — Pipeline de shaders, lecture vidéo, hooks de cycle de vie, et plus.

## Versioning

JOID suit le [semantic versioning](https://semver.org/) pour son API publique :

- **Major** (6.0.0 → 7.0.0) — changements d'API cassants.
- **Minor** (6.0.0 → 6.1.0) — ajouts backward-compatibles.
- **Patch** (6.0.0 → 6.0.1) — corrections de bugs uniquement.

Les classes internes (tout ce qui n'est pas documenté sur ces pages) peuvent changer entre versions mineures sans préavis.
