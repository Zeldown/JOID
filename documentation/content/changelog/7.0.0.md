# 7.0.0 — Unreleased

Engine-agnostic release. The core no longer depends on LWJGL: rendering, window, input and audio go through bridges, and each engine is a backend module of a multi-module Gradle build.

## Highlights

- **Bridge layer** — `IWindowBridge`, `IRenderBridge` and `IAudioBridge` join `IUIBridge` in `BridgeHandler`, which exposes one registry per bridge: `UI`, `WINDOW`, `RENDER`, `AUDIO` and `CLOCK`. Nodes, effects, fonts, resources and video never call an engine directly.
- **Three backends** — `lwjgl2` (OpenGL fixed pipeline), `lwjgl3` (GLFW + OpenGL 3.3 core) and `vulkan` (GLFW + Vulkan 1.3), each with its own `build.gradle` and `DemoWindow`. LWJGL 3 and Vulkan share the `glfw` window module and the `openal` audio module.
- **Same pixels everywhere** — every backend reproduces the 6.x LWJGL 2 output of the demo UIs.
- **Universal shaders** — every shader is written once in JOID GLSL in the `core` module and translated by each backend when it is loaded.
- **Neutral input** — the `Key` enum replaces LWJGL key codes, and mouse coordinates use a top-left origin.
- **Snapshot tests** — every backend renders the demo UIs with a controlled clock and compares them pixel by pixel to its references and to the other backends before each commit.

## Features

### Bridges

- **[Backends](../ui/backends.md)** — New page describing the bridges, the available backends and how to write one.
- **`IRenderBridge`** — Matrix stacks, render state (`pushState` / `popState`, blend, depth, cull, lighting, color mask, alpha test, lines, stencil, viewport), textures, framebuffers, shaders and draw calls.
- **`ShaderSource`** — A parsed JOID GLSL stage (varyings, uniforms, samplers, built-ins and body) passed to `IRenderBridge.createShader`, with `ShaderStage`, `ShaderBuiltin` and `ShaderVariable`.
- **`RenderBridge`** — Base class for emulated backends. Tracks matrices, the normal matrix and the render state in Java.
- **`IWindowBridge`** — Window size, mouse position and grab, keyboard state, clipboard.
- **`IAudioBridge` / `IAudioSource`** — Streaming audio sources used by `VideoAudioPlayer`.
- **`IClockBridge`** — Time of animations, scheduled tasks, text cursors, double clicks and `Node.wait`. `SystemClockBridge` is registered by default, `ManualClockBridge` controls time by hand.
- **Smooth lines** — Lines drawn with `lineSmooth(true)` are expanded by the `Tessellator` and shaded by the core `line` shader, which reproduces the OpenGL antialiased coverage on every backend. `IRenderBridge` exposes `isLineSmooth()`, `getLineWidth()`, `getViewportWidth()` and `getViewportHeight()`.
- **Render types** — `BlendState`, `StencilFunction`, `StencilOperation`, `TextureFilter`, `TextureWrap`, `DrawMode`, `VertexBuffer`, `ITexture`, `IFrameBuffer`, `IShader`.
- **Backends in their own repository** — Releases publish `joid-core` (dev and prod), `joid-testkit`, `joid-glfw`, `joid-openal` and `joid-backend-template`, a Gradle project to develop a backend on the JOID jars only, with its tests, its comparison to the official rendering and its dev and prod jars.
- **`JOID.checkVersion`** — Warns when a backend targets another major version of JOID.

### Tests

- **`testkit` module** — Snapshot test framework (`SnapshotSuite`, `ISnapshotBackend`, scenarios and report) shared by the backend tests.
- **Shader tests** — JUnit tests of `ShaderSource`, of every core shader and of each backend translator. The Vulkan tests compile every core shader with shaderc, and the contract suite of each backend compiles them on the GPU.
- **Snapshot tests** — `./gradlew test` renders the `static`, `interaction`, `transition`, `popup`, `window`, `dev` and `video` scenarios offscreen with a `ManualClockBridge` and compares each shot pixel for pixel to the references of the machine, stored in `.snapshots` and recorded on the first run. `./gradlew updateSnapshots` replaces them, and the interactive `report.html` compares the reference and the render of each shot side by side, by swipe, onion skin, blink, amplified difference or highlighted pixels, down to the pixel.
- **Cross-backend comparison** — `./gradlew crossBackendTest` compares the LWJGL 3 and Vulkan shots to LWJGL 2 with a tolerance of one level per channel.
- **Videos and GIFs** — Snapshot tests capture `UIDemoVideo` and `UIDemoResource`: videos follow the clock, audio is muted, URL resources are cached in `.snapshots/cache`, and `mask` excludes content that cannot be deterministic.
- **Orphan references** — References of shots removed from the scenarios are deleted after the run.
- **Git hooks** — `installLocalGitHook` installs pre-commit and pre-push hooks that test the staged changes or the pushed commits after stashing everything else, and only the modules they touch.
- **Release artifacts** — `./gradlew build` copies every release artifact — the backend, core, testkit, glfw and openal jars and the backend template — into the root `build/libs`, and `./gradlew clean` empties it.
- **Contract tests** — `RenderBridgeContractSuite` checks the render bridge contract without reference images, and each backend runs it in its own JVM.
- **Baselines** — The `SnapshotBackend` of each JOID backend ships in its dev jar, `SnapshotBaseline` renders the scenarios with any `ISnapshotBackend` and `SnapshotComparison` compares directories of shots.

### Input

- **`Key`** — Engine-neutral key enum with `isDown()`.
- **`UI.keybind(Runnable, Key...)`**, **`keyPressed(char, Key, InternalContext)`** and **`NodeKeyPressedCallback`** — Now receive a `Key`.

## Refactors

- **`lib.ui.bridge` → `lib.bridge`** — `BridgeHandler` moves to `lib.bridge`, `IUIBridge` and `UIBridge` to `lib.bridge.ui`.
- **`BridgeHandler`** — The `register` and `get` overloads are replaced by one registry per bridge: `BridgeHandler.UI.register(bridge)`, `BridgeHandler.UI.get(ui)`, `BridgeHandler.RENDER.get()`, `BridgeHandler.WINDOW.get()`, `BridgeHandler.AUDIO.get()`, `BridgeHandler.CLOCK.get()`. Every bridge implements `IBridge` and every registry extends `BridgeRegistry` (`register`, `get`, `find`, `getBridge`), ordered by `getIndex()`.
- **`lib.opengl` → `lib.render`** — `GLTransformation` → `Transformation`, `GLVector` / `GLRotation` / `GLScale` → `Vector` / `Rotation` / `Scale`, `GLTO*` → `*Operation`, `FrameBuffer` → `lib.render.framebuffer.FrameBuffer`.
- **`T9R` → `Tessellator`** — `lib.render.tessellator.Tessellator`, drawing through the render bridge.
- **Shaders** — `IGLShader` → `IShader`, `GLShaderImpl` → `ShaderImpl`, `ShaderBlendState` → `BlendState`. Uniforms move to `lib.bridge.render.shader.uniform`, and `SamplerUniform.setValue` takes an `ITexture`. `IRenderBridge.createShader` takes two `ShaderSource` instead of two `InputStream`.
- **Resources** — Texture ids become `ITexture`: `Resource.getTexture()`, `ResourceData.texture(ITexture)`, `TextureResourceResolver`. `IResourceDecoder.bind` is renamed `update`, and `interpolation` takes a `TextureFilter`.
- **`DrawShape.drawShape(DrawMode, ...)`** — Replaces the GL mode integer. `bindEmptyTexture` is replaced by `IRenderBridge.resetTexture()`.
- **`DraggableProperty.lerp(frameTime, value, target)`** — Takes the frame time in milliseconds, `UI.getFrameTime()`, instead of the fps.

## Removed

- `DemoWindow`, `JOID.main` and the `native/` folder move to the backend modules.
- `GLHelper`, `AllocatedTextureUtil` and `ClipboardUtils` are removed — use the bridges.
- The LWJGL dependency is removed from the core `build.gradle`.
- The `partialTicks` parameter of `onRender` and `onDraw` is removed — callbacks receive `(node, mouseX, mouseY)`.

## Fixes

- **Resource masks** — `UI.startMask(..., Resource)` no longer leaves the alpha test enabled for the following draws.
- **Overflow scroll** — Scrolling while a UI is loading no longer sends the scroll offset to infinity and empties the overflow node: `UI.lerpByFramerate` and `DraggableProperty.lerp` never move past their target and follow the frame time measured on the clock.
- **Vulkan current color** — Draws without vertex colors receive the current color as a float, like OpenGL, instead of a rounded byte, which changed translucent effects by one level.
- **Shader positions** — The core shaders snap `vPosition` to 1/256 of a unit before using it, so gradients, rounded corners, circles and borders no longer depend on the interpolation precision of each engine.
- **Video timing** — `VideoResourceDecoder` displays the frame matching `IClockBridge` and decodes ahead in a bounded queue, instead of pacing its decode thread in real time.
- **`onRender` / `onDraw`** — Callbacks are invoked again: their `partialTicks` parameter never matched the arguments passed by the node, so the reflective call failed on every frame.

## Migration from 6.x

### Breaking changes

- **Register a backend** before loading JOID:

  ```java
  import be.zeldown.joid.impl.lwjgl2.Backend;

  Backend.register();
  BridgeHandler.UI.register(myBridge);
  JOID.inst().load();
  ```

- **Bridge imports** — replace `be.zeldown.joid.lib.ui.bridge.*` with `be.zeldown.joid.lib.bridge.BridgeHandler` and `be.zeldown.joid.lib.bridge.ui.*`.

- **Bridge registries** — `BridgeHandler.register(bridge)` becomes `BridgeHandler.UI.register(bridge)` and `BridgeHandler.get(ui)` becomes `BridgeHandler.UI.get(ui)`.

- **Render callbacks** — drop the last parameter: `node.onRender((n, mouseX, mouseY) -> { })`.

- **Keys** — replace LWJGL key codes with `Key`:

  ```java
  // before
  this.keybind(() -> this.reload(), Keyboard.KEY_R, Keyboard.KEY_LCONTROL);

  // after
  this.keybind(() -> this.reload(), Key.R, Key.LEFT_CONTROL);
  ```

- **Direct GL calls** — go through the render bridge:

  ```java
  // before
  GL11.glPushMatrix();
  GL11.glTranslated(x, y, 0D);

  // after
  final IRenderBridge render = BridgeHandler.RENDER.get();
  render.pushMatrix();
  render.translate(x, y, 0D);
  ```

- **Mouse coordinates** — custom bridges pass coordinates with a top-left origin; `UI.getMouseY()` no longer flips the value.

- **Custom shaders** — rewrite them once in JOID GLSL: remove `#version` and the attribute, matrix and output declarations, then use `aPosition`, `aTexCoord`, `aColor`, `uProjectionMatrix`, `uModelViewMatrix`, `texture(...)` and `fragColor`. `uModelMatrix` and `uViewMatrix` are replaced by `uModelViewMatrix`. See [Custom Shaders](../shaders/custom.md).
