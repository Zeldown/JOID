# 7.0.0 — Unreleased

Engine-agnostic release. The core no longer depends on LWJGL: rendering, window, input and audio go through bridges, and each engine is a backend module of a multi-module Gradle build.

## Highlights

- **Bridge layer** — `IWindowBridge`, `IRenderBridge` and `IAudioBridge` join `IUIBridge` in `BridgeHandler`, which exposes one registry per bridge: `UI`, `WINDOW`, `RENDER` and `AUDIO`. Nodes, effects, fonts, resources and video never call an engine directly.
- **Three backends** — `lwjgl2` (OpenGL fixed pipeline), `lwjgl3` (GLFW + OpenGL 3.3 core) and `vulkan` (GLFW + Vulkan 1.3), each with its own `build.gradle` and `DemoWindow`. LWJGL 3 and Vulkan share the `glfw` window module and the `openal` audio module.
- **Same pixels everywhere** — every backend reproduces the 6.x LWJGL 2 output of the demo UIs.
- **Universal shaders** — every shader is written once in JOID GLSL in the `core` module and translated by each backend when it is loaded.
- **Neutral input** — the `Key` enum replaces LWJGL key codes, and mouse coordinates use a top-left origin.

## Features

### Bridges

- **[Backends](../ui/backends.md)** — New page describing the bridges, the available backends and how to write one.
- **`IRenderBridge`** — Matrix stacks, render state (`pushState` / `popState`, blend, depth, cull, lighting, color mask, alpha test, lines, stencil, viewport), textures, framebuffers, shaders and draw calls.
- **`ShaderSource`** — A parsed JOID GLSL stage (varyings, uniforms, samplers, built-ins and body) passed to `IRenderBridge.createShader`, with `ShaderStage`, `ShaderBuiltin` and `ShaderVariable`.
- **`RenderBridge`** — Base class for emulated backends. Tracks matrices, the normal matrix and the render state in Java.
- **`IWindowBridge`** — Window size, mouse position and grab, keyboard state, clipboard.
- **`IAudioBridge` / `IAudioSource`** — Streaming audio sources used by `VideoAudioPlayer`.
- **Render types** — `BlendState`, `StencilFunction`, `StencilOperation`, `TextureFilter`, `TextureWrap`, `DrawMode`, `VertexBuffer`, `ITexture`, `IFrameBuffer`, `IShader`.

### Input

- **`Key`** — Engine-neutral key enum with `isDown()`.
- **`UI.keybind(Runnable, Key...)`**, **`keyPressed(char, Key, InternalContext)`** and **`NodeKeyPressedCallback`** — Now receive a `Key`.

## Refactors

- **`lib.ui.bridge` → `lib.bridge`** — `BridgeHandler` moves to `lib.bridge`, `IUIBridge` and `UIBridge` to `lib.bridge.ui`.
- **`BridgeHandler`** — The `register` and `get` overloads are replaced by one registry per bridge: `BridgeHandler.UI.register(bridge)`, `BridgeHandler.UI.get(ui)`, `BridgeHandler.RENDER.get()`, `BridgeHandler.WINDOW.get()`, `BridgeHandler.AUDIO.get()`. Every bridge implements `IBridge` and every registry extends `BridgeRegistry` (`register`, `get`, `find`, `getBridge`), ordered by `getIndex()`.
- **`lib.opengl` → `lib.render`** — `GLTransformation` → `Transformation`, `GLVector` / `GLRotation` / `GLScale` → `Vector` / `Rotation` / `Scale`, `GLTO*` → `*Operation`, `FrameBuffer` → `lib.render.framebuffer.FrameBuffer`.
- **`T9R` → `Tessellator`** — `lib.render.tessellator.Tessellator`, drawing through the render bridge.
- **Shaders** — `IGLShader` → `IShader`, `GLShaderImpl` → `ShaderImpl`, `ShaderBlendState` → `BlendState`. Uniforms move to `lib.bridge.render.shader.uniform`, and `SamplerUniform.setValue` takes an `ITexture`. `IRenderBridge.createShader` takes two `ShaderSource` instead of two `InputStream`.
- **Resources** — Texture ids become `ITexture`: `Resource.getTexture()`, `ResourceData.texture(ITexture)`, `TextureResourceResolver`. `IResourceDecoder.bind` is renamed `update`, and `interpolation` takes a `TextureFilter`.
- **`DrawShape.drawShape(DrawMode, ...)`** — Replaces the GL mode integer. `bindEmptyTexture` is replaced by `IRenderBridge.resetTexture()`.

## Removed

- `DemoWindow`, `JOID.main` and the `native/` folder move to the backend modules.
- `GLHelper`, `AllocatedTextureUtil` and `ClipboardUtils` are removed — use the bridges.
- The LWJGL dependency is removed from the core `build.gradle`.
- The `partialTicks` parameter of `onRender` and `onDraw` is removed — callbacks receive `(node, mouseX, mouseY)`.

## Fixes

- **Resource masks** — `UI.startMask(..., Resource)` no longer leaves the alpha test enabled for the following draws.
- **`onRender` / `onDraw`** — Callbacks are invoked again: their `partialTicks` parameter never matched the arguments passed by the node, so the reflective call failed on every frame.

## Migration from 6.x

### Breaking changes

- **Register a backend** before loading JOID:

  ```java
  LWJGL2Backend.register();
  BridgeHandler.UI.register(myBridge);
  JOID.inst().load();
  ```

- **Bridge imports** — replace `be.zeldown.joid.lib.ui.bridge.*` with `be.zeldown.joid.lib.bridge.BridgeHandler` and `be.zeldown.joid.lib.bridge.ui.*`.

- **Bridge registries** — `BridgeHandler.register(bridge)` becomes `BridgeHandler.UI.register(bridge)` and `BridgeHandler.get(ui)` becomes `BridgeHandler.UI.get(ui)`.

- **Render callbacks** — drop the last parameter: `node.onRender((n, mouseX, mouseY) -> { })`.

- **Keys** — replace LWJGL key codes with `Key`:

  ```java
  // before
  this.keybind(() -> this.reload(), Keyboard.KEY_R, Keyboard.KEY_LCONTROL);

  // after
  this.keybind(() -> this.reload(), Key.R, Key.LEFT_CONTROL);
  ```

- **Direct GL calls** — go through the render bridge:

  ```java
  // before
  GL11.glPushMatrix();
  GL11.glTranslated(x, y, 0D);

  // after
  final IRenderBridge render = BridgeHandler.RENDER.get();
  render.pushMatrix();
  render.translate(x, y, 0D);
  ```

- **Mouse coordinates** — custom bridges pass coordinates with a top-left origin; `UI.getMouseY()` no longer flips the value.

- **Custom shaders** — rewrite them once in JOID GLSL: remove `#version` and the attribute, matrix and output declarations, then use `aPosition`, `aTexCoord`, `aColor`, `uProjectionMatrix`, `uModelViewMatrix`, `texture(...)` and `fragColor`. `uModelMatrix` and `uViewMatrix` are replaced by `uModelViewMatrix`. See [Custom Shaders](../shaders/custom.md).
