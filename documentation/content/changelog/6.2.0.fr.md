# 6.2.0 — 2026-04-28

Scopes d'effets, support natif des gradients, et refonte complète du rendu de fonts MSDF.

## Points clés

- **Scopes d'effets** — Les effets déclarent désormais un scope `SELF` ou `CHILDREN` ; texte en gradient + contour peuvent s'empiler sur le même nœud.
- **Support natif des gradients sur `Color`** — `GradientNodeEffect` est retiré ; `Color.toGradient(...)` fonctionne directement sur `RectNode.color(...)`, `BorderNodeEffect`, et `TextInfo`.
- **Refonte du rendu MSDF** — Correction half-texel des UV, alpha supersampled avec offsets clampés, AA basé sur `fwidth`, sampling de l'atlas sans mipmaps. Corrige le flou aux petites tailles et les lignes parasites au-dessus des glyphes selon la position.
- **Compositing premul-correct** dans les shaders border / rounded / circle — fini le trou noir sur les remplissages translucides.

## Fonctionnalités

### Scopes d'effets

- **`NodeEffectScope`** — Nouvelle enum interne sur `NodeEffect`. Deux valeurs : `SELF` (défaut) enveloppe uniquement le draw du nœud, `CHILDREN` enveloppe le rendu des enfants à la place. Voir [Effects Overview](../effects/overview.md#scope).
- **Scope par effet** — `effect.scope(NodeEffectScope.CHILDREN)` surcharge le défaut au moment de l'enregistrement.
- **Flow de rendu de `Node`** — Sépare le pipeline shader en self-passes (enveloppant le draw du nœud) et subtree-passes (enveloppant le draw masqué des enfants).

### Gradients natifs sur Color

- **[`Color.toGradient(other)` / `Color.toGradient(other, direction)`](../drawing/color.md)** — Produit un `Color` gradient utilisable partout où une couleur plate est attendue.
- **`Color.bind(runnable, canvas, hasTexture)`** — Hook interne qui bind le shader gradient nativement, sauvegardant et restaurant le programme précédemment bindé.
- **`GradientShader`** expose désormais `use(..., hasTexture, ...)` pour des gradients texture-aware (utilisé par `ResourceNode` pour teinter les images avec un gradient).
- **`CustomFontProvider`** — Texte en gradient sans pass shader d'enrobage ; le shader font résout le gradient inline via des uniforms dédiés (`u_HasGradient`, `u_GradientStart`, `u_GradientEnd`, `u_GradientStartPos`, `u_GradientEndPos`, `u_GradientCanvas`).
- **`DrawText`** propage le canvas global du texte à `FontProvider.drawText(..., runX, runY, runWidth, runHeight)` pour que les gradients couvrent tout le `Text`, pas chaque `TextElement` séparément.

### Rendu MSDF

- **Pixel-snapping retiré** — Les quads de glyphes sont à nouveau positionnés en sub-pixel ; MSDF est conçu pour ça.
- **Correction half-texel des UV** — `(top - 0.5) / atlasH`, `(left + 0.5) / atlasW`, etc. Empêche `GL_LINEAR` d'échantillonner les glyphs voisins dans l'atlas.
- **`GL_CLAMP_TO_EDGE`** au lieu de `GL_CLAMP` pour les deux `WRAP_S` et `WRAP_T`.
- **Alpha supersampled** dans le fragment shader — 5 samples (centre + 4 diagonales à 0.354 × `dFdx`/`dFdy`), offsets clampés à ±0.5 texel pour empêcher le bleed inter-glyph au minify extrême.
- **AA `screenPxRange`** — `max(0.5 * dot(unitRange, screenTexSize), 1.0)` avec `unitRange = pxRange * texel`. Pilote la largeur de la rampe AA selon le nombre réel de pixels écran, pas une distance hardcodée.
- **Uniform `pxRange`** — Remplace l'ancien duo `doffset` / `blend`. Vient de `Atlas.distanceRange` du JSON de la font.
- **`discard`** quand l'alpha est sous `1/256`, au lieu d'écrire `vec4(0.0)`.

### Pipeline shader

- **`ShaderPass.supportsDirectBind()` défaut à `false`** — Le path direct-bind devient opt-in au lieu d'opt-out. Évite de casser les shaders externes qui dépendent du compositing FBO.
- **`ShaderPipeline` track `pipelineDepth`** au top-level — `render()` incrémente/décrémente via `try/finally`, le path FBO est forcé quand depth > 1.
- **Save/restore de `prevProgram`** autour de chaque appel render — les shaders externes survivent à un appel pipeline interne.
- **`BorderShaderPass.expansion = borderWidth + 2`** avec `texelSize` aligné sur le FBO — élimine le gap d'1 pixel précédemment visible entre fill et contour aux tailles de pixel fractionnaires.

### Shaders border / rounded / circle

- **`border.fsh`** — Compositing premul-correct (fini le trou noir sur les remplissages translucides) ; AA ratio-normalized sur le bord intérieur ; outer fade basé sur `refAlpha` avec samples additionnels à 1.5× et 2.0× distance pour des transitions plus douces sur les formes arrondies.
- **`rounded.fsh` / `circle.fsh`** — Alpha premul-correct au bord du masque quand on échantillonne la texture FBO.

### `RectNode`

- **`border()`** enregistre désormais un `BorderNodeEffect` (scope `SELF`) au lieu de porter un pipeline shader inline.
- **Override `shouldApplyEffect` retiré** — Tous les effets passent par le même mécanisme `NodeEffect`.

### `ResourceNode`

- **`Color.bind(runnable, canvas, hasTexture=true)`** — Les teintes d'image supportent les gradients nativement.

## Suppressions

- **`GradientNodeEffect`** — Remplacé par `Color.toGradient(...)` sur l'API concernée.
- **`GradientShaderPass`** — Plus nécessaire ; `Color.bind` gère le binding gradient directement.

## Migration depuis 6.1.x

### Breaking changes

- **`GradientNodeEffect` retiré.** Remplacer par `Color.toGradient(other)` directement sur `RectNode.color(...)`, `BorderNodeEffect.create(...)`, ou `TextInfo.color(...)`. Conservez votre `Vector4f` direction et passez-la en deuxième arg de `toGradient(other, direction)`.

  ```java
  // avant
  textNode.effect(GradientNodeEffect.create(Color.RED, Color.BLUE));

  // après
  TextNode.create(0, 0).text(Text.create("text", TextInfo.create(font, 24, Color.RED.toGradient(Color.BLUE))));
  ```

- **`GradientShaderPass` retiré.** Si vous utilisiez `ShaderPipeline.render(..., new GradientShaderPass(...), ...)` directement, appelez `Color.bind(runnable, canvas)` à la place.
- **`ShaderPass.supportsDirectBind()` défaut à `false`.** Les implémentations qui dépendaient de l'ancien défaut `true` doivent override et retourner `true` explicitement. Les builtins étaient déjà explicites, donc ça n'impacte que les passes custom.
- **Les fonts MSDF peuvent rendre légèrement différemment** — la rampe AA est désormais basée sur `fwidth`. Si votre atlas a été généré avec `--pxrange` supérieur à 8, regénérez-le avec `--pxrange 4` (range par défaut msdfgen) pour un texte plus net. Sinon le rendu sera techniquement correct mais plus doux qu'avant.

### Ajouts (non-breaking)

- `effect.scope(NodeEffectScope.SELF | NodeEffectScope.CHILDREN)` est opt-in. Les effets existants gardent leur comportement précédent avec le scope `SELF` par défaut.
- `Color.toGradient(...)` est purement additif.
