## Versioning

JOID follows [semantic versioning](https://semver.org/) for its public API:

- **Major** (6.0.0 → 7.0.0) — breaking API changes.
- **Minor** (6.0.0 → 6.1.0) — backward-compatible additions.
- **Patch** (6.0.0 → 6.0.1) — bug fixes only.

Internal classes (anything not documented in these pages) may change between minor versions without notice.
