# 8.0.0

JOID 8.0.0 compared with 7.0.1. Every package moves to `dev.joid`, JOID is released under the [Apache License 2.0](../getting-started/introduction.md), and fonts, resources and state are rebuilt. This page lists the breaking changes by area, then a [migration checklist](#migration-checklist), the new features and the fixes.

## Highlights

- **Reactive setters**: every setter of every node, effect and text takes a value or a `Supplier`. An expression that reads signals, `text(Text.create("Clicks: " + this.clicks.get(), info))`, is followed. See [Signals and State](../concepts/state.md).
- **One property per setter**: `color(c).hoveredColor(h)`, `x(...).y(...)`, `borderColor(c).borderStroke(2D)`.
- **Fonts from `.ttf`/`.otf` files**, with families, CSS weights, kerning, markup, text effects and pixel-art bitmap fonts. See [Text and Fonts](../concepts/text.md).
- **Media**: GIF, APNG, WebP, SVG and transparent WebM behind one playback API. An unreadable resource fails instead of throwing. See [Images and Media](../concepts/media.md).
- **Text fields with a value model**: `accept(...)`, `onChange((field, text, value, valid) -> ...)`, commit on Enter or blur. See [TextFieldNode](../nodes/input/text-field.md).
- **Browser-like mouse**: one target per event, bubbling to the parents, `interactive(false)`, system cursors. See [Input](../concepts/input.md).
- **`UIView`, overlays and interface scale**; pixel-exact rendering and smooth rotated edges on every backend.
- **Self-contained jars**: FFmpeg/JavaCV, JSVG, TwelveMonkeys and a relocated ASM are embedded; prod jars hold no dev tool.

## Breaking changes

Each area gives the renamed or removed API in a table, then the changes that still compile but behave differently.

| --- | --- | --- |

| `getAbsoluteWidth/Height(v)` | `getView().toScreenWidth/Height(v)` | |
| `getRelativeX/Y(v)` | `getView().toUiX/Y(px)` | takes window pixels: `toUiX(v * view.getWidth() / view.getViewportWidth())` |
| `getViewportWidth/Height()` | `getView().getViewportWidth/Height()` | |
| `getX()`, `getY()` | `getView().getOffsetX/Y()` | anchor offset in UI units |
| `updateScaledSize()` | removed | the signals update themselves |

| `UIDataObject`/`UIDataDebugObject`/`UIDataPopupObject.get(Class)` returning `Optional` | the options or `null` | |
| `JOID.open(...)` returning `null` | throws `IllegalStateException` | register a bridge whose `canHandle` accepts the UI |
| `IUIBridge.getInstance()` | removed | delete the override |
| `isOpened(UI)` | `isOpen(UI)` | |
| `JOID.getUI(Class)` | `JOID.getUi(Class)` | |
| `UI.properlyClose()` | `UI.dispose()` | |
| `UI.setRenderPipelineLevel`/`getRenderPipelineLevel` | `setDepthLevel`/`getDepthLevel` | |
| `UI.drawHover(List<String>, x, y)` | `drawHover(Object, x, y)` | a text tooltip is its list of lines |
| `UI.getDevNode()` returning `DevNode` | returns `Node` | DevNode update mode removed, with `getEyeSignal()`, `getReloadSignal()`, `Node.getLastUpdate()` |

- The 1920×1080 canvas keeps a uniform scale at any window ratio (16:10 was stretched); the extra space goes to the anchor side. Fill it with `getView().getVisibleWidth/Height()` or `getViewX/Y/Width/Height()`.
- The zoom is clamped to `[0.1, max(1, 1 / interfaceScale)]` and kept on resize.
- UIs are ordered by `zindex`; the top UI is the first active and visible one, so an inactive or hidden UI no longer takes the mouse from the UIs below.
- Escape goes to a closeable UI first (nodes, keybinds, `keyPressed`, focused field); the UI closes only if nothing consumed it.
- Ctrl+Shift+R (Shift+F5) now replaces the UI with a new instance (`UI.renew()`); Ctrl+R (F5) still reloads `init()`.
- UI data changed at runtime (`getData()`, `getPopup()`, `getDebug()`) applies on the next frame and survives a reload.

- A literal `null` is ambiguous between the value and `Supplier` setters: `hoveredColor((Color) null)`.
- Node setters return the declaring class: call the setters of the node class before those of `Node` (`x`, `visible`...), or add a type witness, `.<RectNode>color(...)`.
- The setters of `ProgressNode`, `ModelNode` and `ModelViewerNode` are `final`; the lifecycle and event methods of built-in nodes (`draw`, `mousePressed`, `keyPressed`...) are no longer `final`.
- `aspectRatio(r)` always means `width = height * r`; `0` is ignored.
- `CircleNode` draws the largest centered circle that fits its bounds.
- Every callback of a type runs, in insertion order; a cancelling `post` no longer stops the others.
- `append` moves a node out of its previous parent. `fireDetach()` ends drag, hover, focus, signal subscriptions and effect `detach`; `onMount` runs again on reattach and a `ResourcePlayerNode` restarts.
- `enabled(false)` disables the children; hidden and disabled nodes receive no input.
- `onScrollEnd` fires once, when the scroll rests at the end; `onScrollEnding` is the early signal.
- `getUi()` during `init()` returns the UI, but `hasUi()` stays `false` until the node is loaded.
- `ReorderableFlexNode` keeps the z-indexes of its children, fires `onReorder` only on a slot change, and `getCurrentIndex()` in its `pre` is the index before the move.
- `ModelViewerNode` turns with the left button only; chart nodes draw a placeholder while they wait.

### Input

| 7.x | 8.0.0 | Note |
| --- | --- | --- |
| `ClickType` (`utils.click`) | `MouseButton` (`input.mouse`) | `getLastClickType()` → `getLastClickButton()` |
| `InternalContext` (`utils.context`) | `DispatchContext` (`ui.node.callback`) | |
| `context.cancel(Supplier<Boolean>)` | `cancelIf(Supplier<Boolean>)` | `cancel(() -> this.x = false)` now always cancels |
| `keyPressed(char c, Key key, context)` (`IUI`, `INode`) | `keyPressed(Key, context)` + `charTyped(int codepoint, context)` | |
| `onKeyPressed((node, c, key) -> ...)` | `onKeyPressed((node, key) -> ...)` + `onCharTyped((node, codepoint) -> ...)` | |
| `UI.fireKeyPressed(char, Key)`, `Node.fireKeyPressed(char, Key, context)` | `fireKeyPressed(Key[, context])` + `fireCharTyped(int[, context])` | |
| `Node.getLastCharacter()` | `getLastCodepoint()` (`int`) | |
| `onMousePressed()`... `onUpdate()`, `onClose()`, `onDetach()` entry points of `UI`/`Node` | `fireMousePressed`, `fireMouseReleased`, `fireMouseDragged`, `fireMouseScroll`, `fireKeyPressed`, `fireUpdate`, `fireClose`, `fireDetach` | `onX` only registers a callback |
| `isHovered(mouseX, mouseY[, checkEnabled])` | `isHovered()`; override `computeHovered()` | `getUi().getNodeAt(x, y)` for another point |
| `mouseScroll(..., int value, context)`, `NodeMouseScrollCallback` | `(..., double notchesX, double notchesY, ...)` | 1 notch instead of 120: `value / 3000D` → `notches / 25D` |
| `setScrollX/Y(float)` | `scrollRatioX/Y(float)` | |
| `setScrollX/Y(double)` | `scrollOffsetX/Y(double)` | |
| `UI.keybind(Runnable, Key...)` | `keybind(Runnable, Object...)` | non-`Key` bindings go through an `IKeyResolver` |
| `getKeybindMap()`: `Map<Key[], Runnable>` | `Map<Set<Object>, Runnable>` | |
| zoom on `+`/`-` characters | `EQUAL`/`MINUS` keys (and numpad) | |

- **Mouse target**: an event goes to the front-most interactive node under the mouse (`UI.getNodeAt(x, y)`), then bubbles to its parents. A sibling drawn over a clickable node (label, icon, veil) takes its click, hover, tooltip and cursor: give it `interactive(false)` or attach it as a child. A parent is hovered while the mouse is over a child that sticks out.
- **Listeners no longer consume**: `onMousePressed`, `onMouseReleased`, `onMouseDragged`, `onMouseScroll` and `onKeyPressed` let the event through; override `post` and call `context.cancel()` to consume. `onClick` still consumes.
- **Tooltips** come from the hovered node or its closest parent with one; `renderHover(...)` draws the node's own tooltip only.
- **Keybinds** fire only when the pressed key belongs to the set; letter keys follow the keyboard layout (`isPhysicalDown()` reads the place).
- **Wheel**: a `SCROLL` node chains the wheel to its parents at its ends; content that overflows both ways scrolls on both axes; `ScrollbarNode` drives the axis of its track.
- **Drag and drop**: only the front draggable node starts and consumes the press; a refused `onDragEnd` puts the node back (or removes the copy); areas apply during the drag; `startDragging`/`dragging(true, ...)` without `draggable(...)` throw; `draggable(...)` stops a running drag.

### Controls and text fields

| 7.x | 8.0.0 | Note |
| --- | --- | --- |
| `TextFieldNode`, `IntegerFieldNode extends TextFieldNode` | `TextFieldNode extends LineFieldNode<String>`, `IntegerFieldNode extends LineFieldNode<Integer>`, `MultilineTextFieldNode extends FieldNode<String>` | shared setters return `FieldNode<V>` mid-chain: field setters first, or `.<TextFieldNode>placeholder(...)` |
| `filter((oldText, newText) -> ...)` | `accept(Predicate<String>)`, `format(UnaryOperator<String>)` | `format` runs on commit |
| `onChange((node, oldText, newText) -> ...)` | `onChange((field, text, value, valid) -> ...)` | runs on every keystroke |
| `IntegerFieldNode.range(min, max)` | `min(...).max(...)`, `step(int)` | |
| `int getValue()` | nullable `getValue()` (`Integer`) | empty stays empty only with `allowEmpty(true)` |
| `margin(margin, cursorMargin)` | `margin(...).cursorMargin(...)` | |
| `align(horizontal, vertical)` (fields, `Text`) | `horizontalAlign(...).verticalAlign(...)` | |
| `SwitchNode.state(String...)` | `states(...)` | |
| `SwitchNode.index(String)` | `state(String)` | |
| `SwitchNode.state(list, index)`, `state(list, state)` | `states(...).index(i)`, `states(...).state(s)` | |
| `SelectorNode` holding nodes | `SelectorNode<V>`: implement `option(V)`, call `values(selected, values...)` | foreign children are removed with an error |
| `selected(Node)` | `value(V)`, `getValue()` | `onChange((node, value) -> ...)` |
| `SliderCursorNode`, `drawCursor`, `cursor(...)`, `getCursor()` | `SliderThumbNode`, `drawThumb`, `thumb(...)`, `getThumb()` | `cursor(...)` now sets the mouse cursor |
| `control.signal(computedSignal)` | `control.value(computedSignal)` | `signal(...)` throws for a `ComputedSignal` |

- Escape in a focused field cancels the edit (restores the text, no `onEnter`) and the UI stays open. Enter, blur, paste and step arrows commit.
- Tab is not a field shortcut. Home/End drop the selection; macOS uses Command and Option.
- `maxTextLength` cuts the inserted text instead of the content; fields keep only typeable characters (U+0020 to U+0233, without U+007F and `§`); `MultilineTextFieldNode` stores `\n` only and shows `<br>` as text.
- Fields draw without markup; `markup(true)` turns the `TextInfo` markups back on.
- `MultilineTextFieldNode` scrolls when the pointer is over it, focused or not.
- The `onChange` of checkbox, toggle, switch, selector and slider runs on every real change: click, setter or bound signal. `signal(...)` binds both ways and replaces the previous signal.
- `SwitchNode` throws `IllegalArgumentException` for an empty list, a bad index or an unknown state, and builds its children once.
- `SliderNode` picks the nearest step and snaps on release; `DoubleSliderNode` steps are exact decimals.

### Signals and state

| 7.x | 8.0.0 | Note |
| --- | --- | --- |
| `signal.getOrDefault()` | `get()` (followed) or `peek()` (not followed) | |
| `watch(signal)` + `onInit(...)` to refresh a value | the expression in the setter, `map(...)` or `Signal.from(...)` | still compiles, no longer refreshes |
| `watch(signal, WatchProperty.RELOAD)` + `onInit` | `WatchProperty.CLEAR_CHILDREN`, `WatchProperty.BODY` + `body(...)` | `WatchProperty` is a class; `custom((node, signal) -> ...)` |
| `visible(node -> flag.getOrDefault())` | `visible(flag)` | |
| a value changing every frame | a lambda, `color(() -> ...)` | read every frame |
| `utils.signal` (with `impl.*`) | `dev.joid.lib.signal` | |
| `SignalSubscriber` | `ISignalSubscriber` | |
| `StoreContext`, `@UIStoreData(context)`, `context()` | `StoreScope`, `@UIStoreData(scope)`, `scope()` | |
| `PERMANENT` store without id in `store/.store` | `store/<class name>.store` | give an id or move the file |

- A watch condition is checked before each change; `false` removes the subscription for good. Its default is "the node's UI is not closed".
- A node subscribes when it is loaded and unsubscribes on detach.
- `set(null)` notifies the default value; `silent()` mutes only the next write; collection signals publish real changes only and never modify their default; `equals`/`hashCode` compare values; `LongSignal.power` is exact and wraps on overflow.
- `LOCAL` stores are recreated when their UI reopens; store files are UTF-8 (7.x files from Windows lose non-ASCII characters); `useStore` needs exactly one matching public constructor.
- `@UIProperty` fields are saved to `<config dir>/property/<UI class>.property`; the config folder (`joid.config`, default `config`) is created on the first write.
- `IIndexedList.getFirst()`/`getLast()` return `null` when empty; an element added again keeps its place.

## Migration checklist

1. **Dependencies**: switch to the `joid-backend-*`/`joid-base-*` artifacts and group `dev.joid`, remove `javacv`, `javacpp`, `ffmpeg` and `commons-compress`. On LWJGL 2, drop the `native` folder and call `Natives.install()`, `Display.create()`, `Backend.register()`. Use the `-dev` jar for dev or demo mode. See [Installation](../getting-started/installation.md).
2. **Packages**: rename the imports, then fix the classes that moved inside the library (fonts, `ResourcePlayerNode`, decoders, `RoundedShaderType`, `CoreShader`).

   ```bash
   grep -rl "be\.zeldown\.joid" src | xargs sed -i -E 's/be\.zeldown\.joid\.impl\.(lwjgl2|lwjgl3|vulkan)/dev.joid.backend.\1/g; s/be\.zeldown\.joid\.impl\.(glfw|openal)/dev.joid.base.\1/g; s/be\.zeldown\.joid/dev.joid/g'
   ```

3. **Fonts**: `MsdfFontLoader.load(new File("Inter-Regular.ttf"), new File("Inter-Bold.ttf")).thenAccept(font -> this.inter = font)`, then `TextInfo.create(this.inter, 16F)` or `TextInfo.create(this.inter, FontWeight.BOLD, 16F)`. Regenerate old atlases with the [MSDF generator](../fonts/custom-fonts.md) or load the `.ttf`. Replace `InternalFont` with your own font.
4. **Text**: convert `letterSpacing` to a fraction and `lineHeight` to a multiple of the font size (or `0`), remove `§`/`[#...]` codes or register an `ITextMarkup`, split `align(h, v)`. Check `UPPER_CAMEL_CASE` and multi-element texts with modifiers.
5. **Coordinates and zoom**: move to `ui.getView()` and `ui.zoom(z)`; to scale from the host, override `IUIBridge.getInterfaceScale(UI)`. See [Canvas and Scaling](../concepts/canvas.md).
6. **Setters**: split every multi-property setter ([Nodes](#nodes), [Controls and text fields](#controls-and-text-fields)); `progress(min, max, v)` becomes the fraction; `borderFill(false)` for open corners.
7. **Signals**: replace `getOrDefault()` with `get()`/`peek()`; move each `watch(signal)` + `onInit` refresh into the setter expression; replace `WatchProperty.RELOAD` with `CLEAR_CHILDREN, BODY` and a `body(...)`; keep `watch` only for structure changes.
8. **Text fields**: replace `filter` with `accept`/`format`, migrate `onChange` to `(field, text, value, valid)`, treat `getValue()` as nullable, react to commits in `onEnter` and on blur if needed.
9. **Controls, effects, layouts**: `SwitchNode.states/state`, `SelectorNode<V>` with `option(V)` and `values(...)`, effects without type argument, `self(node -> node.effect(...))`, swap the `RoundedNodeEffect` sides, `xAxis`/`yAxis`, `getReorderedNode()`/`lock(...)`, slider `thumb`, remove `pipeLineLevel`.
10. **Video**: `VideoPlayerNode` → `ResourcePlayerNode`, `getDecoder()` → `getPlayback()`, `onEnd` for `stop()` → `onStop`.
11. **Resources**: decoder constructors or `ResourceFormat.decoder(...)`, `onError`/`isFailed` instead of `try`/`catch`, `fail(...)` in custom decoders, sprite size in `textureCoords`, `IAssetLocator` for custom inputs, `loop(true)` for GIFs that must loop, `reload()` on each builder.
12. **Input**:
    - `aspectRatio(h / w)` becomes `aspectRatio(w / h)`; test `getCallbackList(...).isEmpty()`; remove duplicate callbacks that relied on being ignored.
    - Give `interactive(false)` to every sibling drawn over a clickable, hoverable, draggable or scrollable node.
    - Replace `isHovered(x, y)` with `isHovered()` and overrides with `computeHovered()`.
    - Split key hooks into `keyPressed(Key)` and `charTyped(int)`; `getLastCodepoint()`.
    - Rename conditional `cancel(...)` to `cancelIf(...)`; cancel the context in `post` to consume input.
    - Take wheel values as `double` notches on two axes; rename `setScroll*` to `scrollRatio*`/`scrollOffset*`; move infinite loading to `onScrollEnding`.
13. **UIs and bridges**:
    - Move `preDraw`/`postDraw`/`drawBackground` into a node with `onDraw` in `init()`, with a `zindex` (`Integer.MAX_VALUE` for over everything), `interactive(false)` and, for window-sized drawing, `x(this::getViewX)`, `y(this::getViewY)`, `width(this::getViewWidth)`, `height(this::getViewHeight)`; per-frame work goes to `update()`.
    - Remove `@UIData(pause)`; replace `Optional` handling of `UIDataObject.get(...)` with a `null` check and `setZlevel` ordering with `setZindex`.
    - Remove the `getInstance()` override and a trivial `isOnTop(UI)`; make sure a bridge accepts each opened UI.
    - Key the keybind map by a `Set` (`new HashSet<>(Arrays.asList(Key.LEFT_CONTROL, Key.S))`).
    - Hosts: forward `keyPressed(Key)` and `charTyped(int)` separately, `mouseMoved()` on every move, `mouseReleased(MouseButton.from(button))`, wheel in notches, and read each returned `boolean`.
    - Give an id to `PERMANENT` stores that had none, rename `StoreContext` to `StoreScope`.
14. **Shaders, drawing, animation**: `bind(ShaderPassContext)` with premultiplied output, `uniform(...)`/`sampler(...)`, `getModelView()`/`getProjection()`/`getState()`, `BlendState.NORMAL`, drop `ITransformOperation.reset()`, `Rotation.ROLL`, `translate` after `start`, paired `bind`/`unbind` (or `fill(...)`), use the equation returned by `s`/`a`/`p`, test `getTimeline() == null`.
15. **Backend implementers**: extend `RenderBridge`, core `Shader` and `Texture`; implement the frame and clear hooks, `drawPrimitive`, `compileProgram`, depth attachments, real mipmaps, 1-pixel lines and normalized lighting; on OpenGL register `GlRenderBridge.create(...)`; update tests to `dev.joid.test.*` and record new snapshots. See [Writing a Backend](../integration/writing-a-backend.md).
16. **Renames**: apply every table above on whole words, then organize imports in the IDE.
17. **Behaviour**: run the UIs and check the bullets under each area, above all mouse targets, `onChange` of controls and fields, Escape, keybinds, drag and drop, wheel chaining, `zindex` order, text wrapping, `drawBorder` corners, 3D model orientation and stores.

## Fixes

- **Fonts and text**: measuring matches drawing (missing glyphs, spaces, re-measure on style change); wrapping at the last fitting space, breaks on `\n`, `\r\n` and `<br>`; `OVERFLOW` never cuts inside a tag; a corrupt font fails its future; MSDF text after a new render bridge; generator contours, bounds and charset parsing.
- **Text fields**: no freeze on clearing a scrolled field; Backspace/Delete with a collapsed selection; both Ctrl keys; click position in offset parents; aligned text scrolling; Up/Down keep the column; AZERTY shortcuts; emoji as one code point; control characters dropped; LWJGL 2 on Retina; `IntegerFieldNode` keeps `-` and clamps long numbers; slider refusal stops the drag.
- **Nodes and layout**: scroll extent covers hanging descendants; `GridNode` rows and hidden children; direction changes reset positions; `ReorderableFlexNode` order with appends and hidden children; `onClick` and `onMousePressed` both fire; failing callback phases are reported; one tooltip at a time; complete `Node.copy()`; `RectNode` hovered getters return `null`; `ModelNode` scales uniformly; `DraggableProperty.copy()` keeps its type.
- **UIs**: hidden or inactive UIs no longer block the mouse and keep drawing their exit transition; opening or closing during a frame skips nothing; reload detaches old nodes; `TransitionState.isRunning()`; `StackUIBridge` screen switch; corrupt `PERMANENT` store files are reset.
- **Rendering**: depth test for 3D models; depth attachment on every framebuffer; state restored when a draw throws; sharp effects and images at any scale, no dark halos; gradients keep rounded and circular masks; `drawCurvedLine` end point; effect priority applied every frame; `BlurNodeEffect` radius `0`.
- **Resources and media**: collected textures released on the render thread; `seek(...)` shows its frame, paused or playing; `restart()` fires `onPlay`; `ResourceBuilder.of(remote, callback)` with a cached asset; `UrlAsset` fallback to `http:`; `ObjModel` parsing.
- **State and color**: `Color.decode("#RRGGBBAA")` round-trips; `Color.bind(...)` restores the previous color; `StringSignal.append`/`concat` on an empty signal; collection signals never publish `null`.
- **Animation**: nested timelines, rewinds, repeats and yoyos; pooled tween limits; two-point `CatmullRom`.
