# 6.0.0 — 2026-04-18

Major alignment release. Brings a full shader pipeline, video playback, lifecycle hooks, extensive fixes, and consolidates the framework around a clean, host-agnostic design.

## Highlights

- **Shader pipeline** — Composable multi-pass GL effects with FBO pooling.
- **Video playback** — `VideoPlayerNode` with FFmpeg-backed decoding.
- **Lifecycle hooks** — `onDetach` callback for cleanup on node removal.
- **Color gradients** — First-class gradient support with smooth transitions.
- **Fixes** — Thread-safe tween manager, hover NPE fixes, scheduled task concurrency, and more.

## Features

### Shaders & effects

- **[ShaderPipeline](../shaders/pipeline.md)** — New multi-pass orchestrator with framebuffer pool and nested expansion support.
- **[Custom shaders](../shaders/custom.md)** — Write your own `ShaderPass` and wire it into the pipeline.
- **[BlurShader + BlurNodeEffect](../effects/blur.md)** — Gaussian blur with dynamic sample count.
- **[BorderShader + BorderNodeEffect](../effects/border.md)** — Outlines with gradient support and IN/OUT modes.
- **[GradientNodeEffect](../effects/gradient.md)** — Linear gradient post-processing for any node (including text).
- **[RoundedNodeEffect](../effects/rounded.md) / [CircleNodeEffect](../effects/circle.md)** — Updated to produce `ShaderPass` via the pipeline.
- **[RectNode](../nodes/design/rect.md)** — Rewritten to route all rendering through the shader pipeline — fixes multi-pass composition for gradient + rounded + circle combinations.
- **BooleanUniform** — New uniform type for shader inputs.

### Video subsystem

- **[VideoPlayerNode](../nodes/design/video-player.md)** — Full playback control: `play / pause / resume / stop / seek / restart`, four callbacks (`onPlay / onPause / onEnd / onProgress`), stretch modes, spatial audio setters.
- **[VideoResourceDecoder](../resources/decoders.md)** — FFmpeg-based decoder supporting MP4/MOV/WebM/MKV/AVI/GIF/APNG with ring buffer + ping-pong textures.
- **VideoAudioPlayer** — OpenAL streaming with pluggable `AudioListener` for distance-based volume fade.
- **[ResourceBuilder.of(InputStream)](../resources/resource-builder.md)** — Now auto-detects video formats via magic bytes and routes to `VideoResourceDecoder` transparently.

### Node & UI

- **[Node detach callback](../nodes/node-fundamentals.md#callbacks)** — New lifecycle hook. `onDetach()` runs when a node is removed via `clearChildren()` or when its UI closes. `VideoPlayerNode` uses it to release its decoder automatically.
- **[Node hoverEquation](../nodes/node-fundamentals.md#hover)** — Customize the easing of the hover fade, default `LINEAR`.
- **[UI closeable property](../ui/ui-class.md#configuration-with-uidata)** — Prevent ESC from closing specific UIs.
- **Node.watch(signal, condition, properties)** — Conditional watches that only trigger when a predicate is true.
- **UI.current** — Static reference to the UI currently in `init()`, exposed so nodes created before attachment can resolve `getUi()`.

### API ergonomics

- **[TextFieldNode / MultilineTextFieldNode](../nodes/design/text-field.md)** — New `cursorPosition(int)` setter.
- **[Color transitions for gradients](../drawing/color.md#transitions)** — `Color.transition` now handles all 4 combinations of flat/gradient.
- **DrawShape.drawRawRect** — New method for raw shader composition.

## Fixes

- **TweenManager thread-safety** — All mutations now wrapped in `synchronized(lock)`.
- **Concurrent scheduled task list** — `UI.scheduledTaskList` is now a `CopyOnWriteArrayList` — no more `ConcurrentModificationException`.
- **CustomHoverElement NPE** — Null guards on `element` / `position`, missing `FIXED` case added.
- **NodeHoverElement out-of-screen** — Tooltips now clamp to screen bounds, preventing clipping at the right/top edges.
- **GridNode verticalMargin** — Trailing margin removed from grid height calculation.
- **TextInfo italic** — `isItalic()` is now honored by `CustomFontProvider`.
- **GL_GREATER alpha** — `glAlphaFunc` moved out of projection block — now applied unconditionally.
- **Better `Node.getUi()`** — Falls back to `UI.getCurrent()` during `init()` so nodes can resolve their UI before attachment.
- **FrameBuffer GL portability** — Switched from `GL32.glFramebufferTexture` to `GL30.glFramebufferTexture2D` for broader driver compat.
- **UIData.zoomable default** — Now defaults to `true` (was `false`), matching expected UX.
- **OpenAL lifecycle** — `AL.create()` wrapped in `ensureOpenALLoaded()` with fallback; shutdown hook added for `AL.destroy()`.
- **Node dragging** — `CALLBACK_DRAG` now fires in `onMouseDragged` (was in `render`, caused stale coords).
- **Version display** — `JOID.VERSION` constant, kept in sync with `build.gradle` via the `updateVersion` task.

## Refactors

- **GifResourceDecoder removed** — Replaced by `VideoResourceDecoder` (handles GIF, APNG, and more via FFmpeg).
- **DEFAULT_CACHE** moved from `Resource` to `ResourceBuilder` as a shared global cache.
- **All javadoc removed** — JOID codebase follows a zero-javadoc policy; the documentation you're reading is the source of truth.

## New demo UIs

- **UIDemoShader** — showcases all shader effects: rounded, circle, blur, border (IN/OUT), gradients, text with gradient & border.
- **UIDemoVideo** — bouncing video player with fullscreen toggle, pause/resume, live FPS/RAM/decoder stats.

## Migration from 5.1.0

### Breaking changes

- `GifResourceDecoder` is removed. If you instantiated it directly, replace with `ResourceDecoder.video(stream)` or simply `Resource.of(stream)` (auto-detection handles it).
- `UIData.zoomable` default changed from `false` to `true`. If you want the old behavior, set `@UIData(zoomable = false)` explicitly or call `ui.getData().setZoomable(false)`.
- `Color.transition` now returns gradient results when either input is a gradient. If you assumed flat output, check `.isGradient()` before using `.r/.g/.b/.a` directly.

### Additions (non-breaking)

Everything else is additive. You can upgrade without changes, and gradually adopt new features (effects, video, stores, etc.) as needed.
