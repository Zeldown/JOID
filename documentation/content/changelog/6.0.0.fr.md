# 6.0.0 — 2026-04-18

Release majeure d'alignement. Apporte un pipeline de shaders complet, la lecture vidéo, les hooks de cycle de vie, de nombreuses corrections, et consolide le framework autour d'un design propre, agnostique à l'hôte.

## Points forts

- **Pipeline de shaders** — Effets GL multi-passes composables avec pool de FBOs.
- **Lecture vidéo** — `VideoPlayerNode` avec décodage basé sur FFmpeg.
- **Hooks de cycle de vie** — Callback `onDetach` pour le cleanup au retrait de nœud.
- **Gradients de couleur** — Support de gradient first-class avec transitions douces.
- **Corrections** — Tween manager thread-safe, fixes NPE de hover, concurrence des tâches planifiées, et plus.

## Fonctionnalités

### Shaders & effets

- **[ShaderPipeline](../shaders/pipeline.md)** — Nouvel orchestrateur multi-passes avec pool de framebuffers et support d'expansion imbriquée.
- **[Custom shaders](../shaders/custom.md)** — Écrire votre propre `ShaderPass` et le câbler dans le pipeline.
- **[BlurShader + BlurNodeEffect](../effects/blur.md)** — Flou gaussien avec nombre d'échantillons dynamique.
- **[BorderShader + BorderNodeEffect](../effects/border.md)** — Contours avec support gradient et modes IN/OUT.
- **[GradientNodeEffect](../effects/gradient.md)** — Post-processing gradient linéaire pour tout nœud (y compris texte).
- **[RoundedNodeEffect](../effects/rounded.md) / [CircleNodeEffect](../effects/circle.md)** — Mis à jour pour produire des `ShaderPass` via le pipeline.
- **[RectNode](../nodes/design/rect.md)** — Réécrit pour router tout le rendu via le pipeline de shaders — corrige la composition multi-passes pour les combinaisons gradient + rounded + circle.
- **BooleanUniform** — Nouveau type d'uniform pour entrées de shader.

### Sous-système vidéo

- **[VideoPlayerNode](../nodes/design/video-player.md)** — Contrôle complet : `play / pause / resume / stop / seek / restart`, quatre callbacks (`onPlay / onPause / onEnd / onProgress`), modes de stretch, setters d'audio spatial.
- **[VideoResourceDecoder](../resources/decoders.md)** — Décodeur basé sur FFmpeg supportant MP4/MOV/WebM/MKV/AVI/GIF/APNG avec ring buffer + textures ping-pong.
- **VideoAudioPlayer** — Streaming OpenAL avec `AudioListener` enfichable pour fade de volume par distance.
- **[ResourceBuilder.of(InputStream)](../resources/resource-builder.md)** — Auto-détecte maintenant les formats vidéo via magic bytes et route vers `VideoResourceDecoder` de façon transparente.

### Node & UI

- **[Callback detach de Node](../nodes/node-fundamentals.md#callbacks)** — Nouveau hook de cycle de vie. `onDetach()` se déclenche quand un nœud est retiré via `clearChildren()` ou à la fermeture de son UI. `VideoPlayerNode` l'utilise pour libérer son décodeur automatiquement.
- **[Node hoverEquation](../nodes/node-fundamentals.md#hover)** — Personnaliser l'easing du fade de hover, défaut `LINEAR`.
- **[Property closeable d'UI](../ui/ui-class.md#configuration-via-uidata)** — Empêcher ESC de fermer certaines UIs.
- **Node.watch(signal, condition, properties)** — Watches conditionnels qui ne se déclenchent que si un prédicat est vrai.
- **UI.current** — Référence statique à l'UI actuellement dans `init()`, exposée pour que les nœuds créés avant attachement puissent résoudre `getUi()`.

### Ergonomie d'API

- **[TextFieldNode / MultilineTextFieldNode](../nodes/design/text-field.md)** — Nouveau setter `cursorPosition(int)`.
- **[Transitions de couleur pour gradients](../drawing/color.md#transitions)** — `Color.transition` gère maintenant les 4 combinaisons flat/gradient.
- **DrawShape.drawRawRect** — Nouvelle méthode pour composition de shader brute.

## Corrections

- **Thread-safety de TweenManager** — Toutes les mutations wrappées dans `synchronized(lock)`.
- **Liste de tâches planifiées concurrente** — `UI.scheduledTaskList` est maintenant une `CopyOnWriteArrayList` — fini les `ConcurrentModificationException`.
- **NPE CustomHoverElement** — Guards de null sur `element` / `position`, cas `FIXED` manquant ajouté.
- **NodeHoverElement hors écran** — Les infobulles clampent maintenant aux bords d'écran, évitant le clipping en haut/à droite.
- **GridNode verticalMargin** — Marge de fin retirée du calcul de hauteur de la grille.
- **TextInfo italic** — `isItalic()` est maintenant honoré par `CustomFontProvider`.
- **Alpha GL_GREATER** — `glAlphaFunc` déplacé hors du bloc de projection — appliqué maintenant inconditionnellement.
- **Meilleur `Node.getUi()`** — Fallback sur `UI.getCurrent()` pendant `init()` pour que les nœuds puissent résoudre leur UI avant attachement.
- **Portabilité GL de FrameBuffer** — Switch de `GL32.glFramebufferTexture` vers `GL30.glFramebufferTexture2D` pour une compat pilote plus large.
- **Défaut UIData.zoomable** — Maintenant `true` par défaut (était `false`), correspondant à l'UX attendue.
- **Cycle de vie OpenAL** — `AL.create()` wrappé dans `ensureOpenALLoaded()` avec fallback ; shutdown hook ajouté pour `AL.destroy()`.
- **Drag de Node** — `CALLBACK_DRAG` se déclenche maintenant dans `onMouseDragged` (était dans `render`, causait des coords périmées).
- **Affichage de version** — constante `JOID.VERSION`, maintenue en phase avec `build.gradle` via la tâche `updateVersion`.

## Refactorings

- **GifResourceDecoder retiré** — Remplacé par `VideoResourceDecoder` (gère GIF, APNG, et plus via FFmpeg).
- **DEFAULT_CACHE** déplacé de `Resource` vers `ResourceBuilder` comme cache global partagé.
- **Toute la javadoc retirée** — le codebase JOID suit une politique zéro-javadoc ; la documentation que vous lisez est la source de vérité.

## Nouvelles UIs de démo

- **UIDemoShader** — présente tous les effets shader : rounded, circle, blur, border (IN/OUT), gradients, texte avec gradient et bordure.
- **UIDemoVideo** — lecteur vidéo rebondissant avec toggle plein écran, pause/resume, stats live FPS/RAM/décodeur.

## Migration depuis 5.1.0

### Changements cassants

- `GifResourceDecoder` est retiré. Si vous l'instanciiez directement, remplacez par `ResourceDecoder.video(stream)` ou simplement `Resource.of(stream)` (l'auto-détection s'en occupe).
- Le défaut `UIData.zoomable` est passé de `false` à `true`. Si vous voulez l'ancien comportement, mettez `@UIData(zoomable = false)` explicitement ou appelez `ui.getData().setZoomable(false)`.
- `Color.transition` retourne maintenant des résultats gradient si une des entrées est un gradient. Si vous assumiez une sortie flat, vérifiez `.isGradient()` avant d'utiliser `.r/.g/.b/.a` directement.

### Ajouts (non cassants)

Tout le reste est additif. Vous pouvez upgrader sans changements et adopter progressivement les nouvelles fonctionnalités (effets, vidéo, stores, etc.).
