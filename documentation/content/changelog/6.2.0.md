# 6.2.0 — 2026-04-28

Effect scopes, native gradient support, and a complete rework of MSDF font rendering.

## Highlights

- **Effect scopes** — Effects now declare `SELF` or `CHILDREN` scope; gradient text + outline can stack on the same node.
- **Native gradient support on `Color`** — `GradientNodeEffect` is gone; `Color.toGradient(...)` works directly on `RectNode.color(...)`, `BorderNodeEffect`, and `TextInfo`.
- **MSDF font rendering rework** — Half-texel UV correction, supersampled alpha with clamped offsets, fwidth-based AA, mipmap-free atlas sampling. Fixes blur at small sizes and the position-dependent ghost lines above glyphs.
- **Premul-correct compositing** in border / rounded / circle shaders — no more dark gap on translucent fills.

## Features

### Effect scopes

- **`NodeEffectScope`** — New inner enum on `NodeEffect`. Two values: `SELF` (default) wraps only the node's own draw, `CHILDREN` wraps the children rendering instead. See [Effects Overview](../effects/overview.md#scope).
- **Per-effect scope** — `effect.scope(NodeEffectScope.CHILDREN)` overrides the default per registration.
- **`Node` render flow** — Splits the shader pipeline into self-passes (wrapping the node draw) and subtree-passes (wrapping the masked children draw).

### Native Color gradient

- **[`Color.toGradient(other)` / `Color.toGradient(other, direction)`](../drawing/color.md)** — Produces a gradient `Color` usable everywhere a flat color is.
- **`Color.bind(runnable, canvas, hasTexture)`** — Internal hook that binds the gradient shader natively, saving and restoring the previously bound program.
- **`GradientShader`** now exposes `use(..., hasTexture, ...)` for texture-aware gradients (used by `ResourceNode` to tint images with a gradient).
- **`CustomFontProvider`** — Gradient text without a wrapping shader pass; the font shader resolves the gradient inline via dedicated uniforms (`u_HasGradient`, `u_GradientStart`, `u_GradientEnd`, `u_GradientStartPos`, `u_GradientEndPos`, `u_GradientCanvas`).
- **`DrawText`** propagates the global text canvas to `FontProvider.drawText(..., runX, runY, runWidth, runHeight)` so gradients span the whole `Text`, not each `TextElement` separately.

### MSDF font rendering

- **Pixel-snapping removed** — Glyph quads are positioned at sub-pixel precision again; MSDF was designed for this.
- **Half-texel UV correction** — `(top - 0.5) / atlasH`, `(left + 0.5) / atlasW`, etc. Stops `GL_LINEAR` from sampling neighbour glyphs in the atlas.
- **`GL_CLAMP_TO_EDGE`** instead of `GL_CLAMP` for both `WRAP_S` and `WRAP_T`.
- **Supersampled alpha** in the fragment shader — 5 samples (centre + 4 diagonals at 0.354 × `dFdx`/`dFdy`), offsets clamped to ±0.5 texel to prevent inter-glyph bleed at extreme minify.
- **`screenPxRange` AA** — `max(0.5 * dot(unitRange, screenTexSize), 1.0)` with `unitRange = pxRange * texel`. Drives the AA ramp width based on actual screen pixel count, not a hardcoded distance.
- **`pxRange` uniform** — Replaces the old `doffset` / `blend` pair. Comes from `Atlas.distanceRange` of the font's JSON.
- **`discard`** when alpha is below `1/256`, instead of writing `vec4(0.0)`.

### Shader pipeline

- **`ShaderPass.supportsDirectBind()` defaults to `false`** — Direct-bind path is opt-in instead of opt-out. Avoids breaking outer shaders that rely on FBO composition.
- **`ShaderPipeline` tracks `pipelineDepth`** at the top level — `render()` increments/decrements via `try/finally`, the FBO path is forced when depth > 1.
- **`prevProgram` save/restore** around every render call — outer shaders survive an inner pipeline call.
- **`BorderShaderPass.expansion = borderWidth + 2`** with `texelSize` matched to the FBO — eliminates the 1-pixel gap previously visible between fill and outline at fractional pixel sizes.

### Border / rounded / circle shaders

- **`border.fsh`** — Premul-correct compositing (no more dark gap on translucent fills); ratio-normalized AA on the inner edge; `refAlpha`-based outer fade with extra samples at 1.5× and 2.0× distance for smoother transitions on rounded shapes.
- **`rounded.fsh` / `circle.fsh`** — Premul-correct alpha at the mask edge when sampling from the FBO texture.

### `RectNode`

- **`border()`** now registers a `BorderNodeEffect` (scope `SELF`) instead of carrying a separate inline shader pipeline.
- **`shouldApplyEffect` override removed** — All effects now flow through the same `NodeEffect` mechanism.

### `ResourceNode`

- **`Color.bind(runnable, canvas, hasTexture=true)`** — Image tints support gradient natively.

## Removals

- **`GradientNodeEffect`** — Replaced by `Color.toGradient(...)` on the relevant API.
- **`GradientShaderPass`** — No longer needed; `Color.bind` handles gradient binding directly.

## Migration from 6.1.x

### Breaking changes

- **`GradientNodeEffect` removed.** Replace with `Color.toGradient(other)` directly on `RectNode.color(...)`, `BorderNodeEffect.create(...)`, or `TextInfo.color(...)`. Keep your direction `Vector4f` and pass it as the second arg to `toGradient(other, direction)`.

  ```java
  // before
  textNode.effect(GradientNodeEffect.create(Color.RED, Color.BLUE));

  // after
  TextNode.create(0, 0).text(Text.create("text", TextInfo.create(font, 24, Color.RED.toGradient(Color.BLUE))));
  ```

- **`GradientShaderPass` removed.** If you used `ShaderPipeline.render(..., new GradientShaderPass(...), ...)` directly, call `Color.bind(runnable, canvas)` instead.
- **`ShaderPass.supportsDirectBind()` defaults to `false`.** Implementations that relied on the old `true` default need to override and return `true` explicitly. The built-ins were already explicit, so this only matters for custom passes.
- **MSDF fonts may render slightly differently** — the AA ramp is fwidth-based now. If your atlas was generated with a `--pxrange` greater than 8, regenerate it with `--pxrange 4` (msdfgen default range) for sharper text. Otherwise rendering will be technically correct but softer than before.

### Additions (non-breaking)

- `effect.scope(NodeEffectScope.SELF | NodeEffectScope.CHILDREN)` is opt-in. Existing effects keep their previous behavior with the default `SELF` scope.
- `Color.toGradient(...)` is purely additive.
